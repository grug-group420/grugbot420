# Default Specimen Seed Commands
# ===============================
# This file is the canonical seed for grugbot420's `default.specimen.gz`.
# Each line is a CLI command piped to `src/Main.jl`. Empty lines and lines
# starting with `#` are skipped by the build script.
#
# To rebuild the specimen:
#   bash scripts/build_default_specimen.sh
#
# The resulting `grug-binary/default.specimen.gz` ships with the engine and
# auto-loads on first boot when no other specimen is provided.
