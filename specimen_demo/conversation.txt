# ============================================================================
# GRUG COMPREHENSIVE SPECIMEN CONVERSATION SCRIPT

# Runs after the specimen is built/loaded. Mixes /mission (standard jitter,
# ratio=0.03) and /brainstorm (heavy scoped jitter, ratio=0.08, coin=0.05)
# prompts across all four subject lobes so we can compare snap-back vs
# far-jump behavior on parallel questions. Baseline /status is captured
# once right after load; final /status + /aimlStatus at the end.
#
# SCOPE NOTE:
#   The engine's Fresh Memory rolls the last 5 system messages into every
#   /mission's generated payload verbatim, and each payload is itself
#   stored as a system message. That creates an O(N^2) context bloat
#   across many missions — 20+ missions can balloon the raw stdout past
#   1 GB and OOM on smaller sandboxes. We therefore keep the conversation
#   to 8 missions across 4 subjects (two per subject, one /mission and one
#   /brainstorm each). This is still enough to compare snap-back vs
#   far-jump behavior per lobe while keeping the raw log well under
#   100 MB uncompressed.
# ============================================================================
