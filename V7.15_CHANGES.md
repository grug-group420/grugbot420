## Design principles honored

- **No silent failures.** Every public mutator validates before state
  mutation. Every error path throws a typed exception with a named context.
  Every rejection in a round-runner is counted, not swallowed.
- **GRUG comment style.** Every file carries inline `# GRUG:` cave-speak
  comments. Every module has an academic header block. Every constant has
  a comment explaining its chosen value.
- **Thread safety.** Every shared Dict / Vector / counter uses a
  `ReentrantLock`. Atomic claim/release on `CrossTalkGate` and
  `can_chatter_now` cooldown map.
- **Bounded work.** `PER_LOBE_FIRE_CAP = 1000`, `CROSS_TALK_ACTIVE_CAP = 1000`,
  `CHATTER_WINDOW_MAX = 400`, `CHATTER_COOLDOWN_SECONDS = 3600` --- every
  loop that could grow is capped.
- **Zero-overhead simple path.** Dynamic action/tone and jitter override
  both short-circuit to bit-exact legacy behavior when their gate predicate
  returns false. Complex inputs pay for the dynamic path; simple ones don't.

## Remaining integration work (engine.jl call-site wiring)

These are the **integration hooks** into existing engine.jl code paths. The
new modules are fully implemented, tested, and exported; the actual wiring
into engine.jl's fire loop is intentionally **not** done in this branch to
keep the diff reviewable. The hooks are:

- `engine.jl::fire_attachments!` should call `CrystalizeTag.is_crystalized`
  before the strength-biased coinflip and short-circuit to always-fire.
- `engine.jl::scan_and_expand` should group votes by lobe and hand them to
  `LobeOrchestrator.summarize_lobe_votes` + `compute_orchestration_plan`,
  then dispatch in sequence/async per the returned plan.
- `PhagyMode.jl::phagy_dispatch` should add `PhagyGroupOrganizer` as a
  seventh automaton in the selection roulette.

The modules are intentionally **pure** so these wiring points can be done
surgically without risk to the 25-file regression baseline.
