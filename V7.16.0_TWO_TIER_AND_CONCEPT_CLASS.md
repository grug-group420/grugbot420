# v7.16.0 — Two-Tier AIML Threshold + Concept-Class Thesaurus

## Summary

Two architectural improvements land together:

1. **Two-tier vote rendering** — Low-confidence votes no longer babble. The
   orchestrator already produced three bands (top / subtop / rejected), but the
   AIML rendering layer was flattening them into a single inline action-list.
   Rewritten to route top band as the main claim and mid-band votes as
   "Grug also sure of ..." trailing support.
2. **Concept-class thesaurus** — Added a new relation type in Thesaurus and
   NegativeThesaurus where words are matched as equivalence groups (not pairwise
   intensity scores). Widens the synthesis vocabulary pool and enables
   "ban-a-whole-concept" inhibition.

## Part 1 — Two-Tier Vote Rendering

### The bug

In v7.15.x Turn 6 of the seeded conversation test produced:

> "favor explain but keep explain, explain, explain, explain, describe,
> describe, explain, describe ready"

Eight weak-confidence nodes (~0.16 each) voted "explain" and "describe". The
old code emitted them inline in the action-list template, producing noise-as-signal.

### Root causes

1. `AIML_CONFIDENCE_THRESHOLD` was 0.15 — too loose; let sub-threshold voters
   into the rendering pipeline.
2. `{SURE_ACTIONS}` / `{UNSURE_ACTIONS}` / `{ALL_ACTIONS}` rule interpolations
   used raw `[v.action for v in votes]` with no dedup — 18 describe votes
   rendered as "describe, describe, describe, describe, ..." verbatim.
3. The three-band split existed in `VoteOrchestrator.select_aiml_votes` but the
   rendering layer flattened the subtop band into `unsure_votes` and used it
   only as a flat hedge, losing the semantic distinction between
   "confident supporter" and "quiet hedge voice".

### Fixes

- **`src/VoteOrchestrator.jl`**
  - `AIML_CONFIDENCE_THRESHOLD` raised 0.15 → 0.20
  - New constant `AIML_SUPPORT_FLOOR = 0.35` separates mid-band support from
    lower-confidence hedge
  - New function `select_aiml_votes_banded` returns a NamedTuple with four
    explicit bands: `top`, `support`, `hedge`, `rejected`

- **`src/Main.jl`**
  - New module-level `_CURRENT_BAND_INFO` + `band_of(node_id)` side-channel so
    `generate_aiml_payload` can distinguish support from hedge without
    breaking the existing COMMANDS signature
  - `ephemeral_aiml_orchestrator` calls the new banded selector, populates
    band info under a try/finally (cleared on exit even if COMMANDS throws)
  - `generate_aiml_payload` rewritten: support band renders as dedicated
    "Grug also sure of: <pattern>" sentences AFTER the main claim (cap 2);
    hedge band renders as the compact "I am not fully locked in — X is
    also on the table" hedge (deduplicated actions)
  - All `{SURE_ACTIONS}` / `{UNSURE_ACTIONS}` / `{ALL_ACTIONS}` interpolations
    now pass through `unique!` before string-join
  - Debug telemetry gained a `Support Actions` and `Hedge Actions` line so
    operators can see where each vote landed

### Result

Same seeded conversation under v7.16.0:

Before (v7.15.3):
> "favor explain but keep explain, explain, explain, explain, describe,
> describe, explain, describe ready"

After (v7.16.0):
> "Here is the picture: neural networks improve patterns from training data.
> Grug also sure of: computers process stats using binary argument gates.
> Grug also sure of: bees pollinate flowers and craft honey. I am not fully
> locked in — warn and portray is also on the table."

## Part 2 — Concept-Class Thesaurus

### Motivation

Seed synonyms (pairwise intensity-weighted) miss a common case: words/phrases
that aren't *similar* but are *interchangeable in context*. Examples:

- `question` / `probe` / `inquire` / `interrogate` are all "inquiry" verbs
- `help` / `assist` / `aid` / `support` / `guide` are all "assistance"
- `agree` / `endorse` / `affirm` / `confirm` are all "agreement"

Pairwise seed synonyms don't capture these — the words diverge structurally
(different stems, different lengths) but are semantically equivalent for
orchestration purposes.

### Design

**Concept classes** are named equivalence groups:
- A class has a canonical name and a set of member words
- Any member is interchangeable with any other — no intensity ranking
- A word can belong to multiple classes (e.g. "probe" is both `:inquiry`
  and `:tool`)
- Coexists with pairwise synonyms; `_pick_synonym` consults both

### Files changed

- **`src/Thesaurus.jl`** — new subsystem:
  - `CONCEPT_CLASS_MEMBERS` (concept → member set)
  - `CONCEPT_CLASS_REVERSE` (word → classes it belongs to)
  - `CONCEPT_CLASS_LOCK` (guards both)
  - 13 seeded classes (inquiry, assistance, danger, agreement, refusal,
    investigation, change, creation, destruction, understanding,
    communication, emotion_positive, emotion_negative)
  - API: `add_concept_class!`, `remove_concept_class!`,
    `get_concept_equivalents`, `concept_classes_of`,
    `list_concept_classes`, `concept_class_count`
  - NO SILENT FAILURES — empty name, empty member list, whitespace-only
    members all throw ThesaurusError

- **`src/InputQueue.jl`** — concept-class inhibition mirror:
  - `_NEG_CONCEPT_BANS` (separate registry from word-level `_NEG_THESAURUS`)
  - `is_inhibited(word)` now returns true on EITHER word ban OR any
    concept-class ban containing the word
  - New helpers: `is_concept_inhibited`, `add_concept_inhibition!`,
    `remove_concept_inhibition!`, `list_concept_inhibitions`,
    `concept_inhibition_count`
  - Reaches Thesaurus via parentmodule introspection so unit tests of
    InputQueue alone still load cleanly
  - NO SILENT FAILURES — banning unknown concept throws, duplicate ban throws

- **`src/Main.jl`** — wiring:
  - `_pick_synonym` now pulls concept-class siblings into the candidate
    pool alongside `Thesaurus.SYNONYM_SEED_MAP` and
    `SemanticVerbs._SYNONYM_MAP`
  - Seven new CLI commands with immune-gate integration:
    - `/conceptClass add <name> <word1> <word2> ...`
    - `/conceptClass remove <name>`
    - `/conceptClass list`
    - `/conceptClass of <word>`
    - `/conceptInhibit add <name> [--reason <text>]`
    - `/conceptInhibit remove <name>`
    - `/conceptInhibit list`

- **`test/test_concept_class.jl`** — new test module, 40 assertions:
  - Seed classes load correctly
  - Bidirectional insert / reverse-index
  - Idempotent merge
  - Input validation (empty name, empty members, whitespace-only)
  - Unknown word returns empty set
  - Concept ban bans all members
  - Unknown concept throw on ban
  - Duplicate ban throw
  - Word-level and concept-level bans compose (OR)
